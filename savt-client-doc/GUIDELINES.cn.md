## :round_pushpin: 步骤 2：安装软件

安装过程应不超过 **2 分钟**。

请注意，您的计算机上需要预先安装 PCAP 库。不同操作系统的处理方式各异，请按照下列说明操作。

### Windows

1. 双击 savt-client.exe 安装包，安装向导将检查包括 PCAP 在内的依赖项。

### MacOS

1. 在终端中执行以下一键安装命令
    ```bash
    curl -sSL https://ki3.org.cn/public/sav/requirements_check/mac_install_savt_client_rq.sh | bash
    ```
2. 双击 savt-client.dmg 安装包

### Linux

1. 在终端中执行以下一键安装命令
    ```bash
    curl -sSL https://ki3.org.cn/public/sav/requirements_check/linux_install_savt_client_rq.sh | bash
    ```

   注意：如果安装向导提示您手动安装 PCAP，您可以从 [官方网站](https://GitHub.com/his-tcpdump-group) 获取。
2. 下载 savt-client.tar.gz 包，并查看包内的 READ.md 文件

---

## :round_pushpin: 步骤 3：启动软件

启动过程应在 **1 分钟内**完成。

对于 Windows 和 MacOS 用户，请在系统应用程序中搜索 savt-client 并点击启动。

对于 Linux 用户，请按照 README.md 中的说明启动软件。
