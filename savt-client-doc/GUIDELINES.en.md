## :round_pushpin: Step 2：Install the Software.



The installation process should take **less than 2 minutes**.

It is worth noting that the PCAP library needs to be pre-installed on your computer. Different operating systems have different processing methods. Please follow the following.

### Windows

1. Just double-click the savt-client.exe installation package. The installation wizard will check dependencies such as PCAP.

### MacOS

1. Execute the following one-click installation command in the terminal
    ``` bash
    curl -sSL https://ki3.org.cn/public/sav/requirements_check/mac_install_savt_client_rq.sh | bash
    ```
2. Double-click the savt-client.dmg installation package

### Linux
1. Execute the following one-click installation command in the terminal

    ``` bash
    curl -sSL https://ki3.org.cn/public/sav/requirements_check/linux_install_savt_client_rq.sh | bash
    ```
   
    Note: If the installation wizard prompts you to manually install PCAP, you can get it from the [official website](https://GitHub.com/his-tcpdump-group).
2. Download savt-client.tar.gz package and view the contents of READ.md in the package


## :round_pushpin: Step 3：Launch the software.
The launching process should complete in **less than one minute**. 

For Windows and MacOS users, search for savt-client in the system applications and click to start it.

For Linux, Please follow the instructions in README.md to start it.
