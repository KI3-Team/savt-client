# 欢迎

测试者，您好！在开始测试之前，我们需要检查您的IP地址。请根据您的操作系统按照以下说明找到您的**本地IPv4地址**：

## Windows 11
1. 打开Windows**开始**菜单并点击**设置**。

    ![Alt](/public/sav/ip_nat_check_ch/ip_nat_check_11_ch.png =750x)

2. 在左侧面板中点击**网络与Internet**，然后点击**属性**。

    ![Alt](/public/sav/ip_nat_check_ch/ip_nat_check_12_ch.png =750x)

3. 在这里，您可以看到您的本地**IPv4地址**。

    ![Alt](/public/sav/ip_nat_check_ch/ip_nat_check_13_ch.png =750x)

## Windows 10
1. 打开Windows**开始**菜单并点击**设置**。

    ![Alt](/public/sav/ip_nat_check_ch/ip_nat_check_21_ch.png =350x)

2. 选择**网络与Internet**。

    ![Alt](/public/sav/ip_nat_check_ch/ip_nat_check_22_ch.png =750x)

3. 在左侧面板中选择**Wi-Fi**，然后点击**高级设置**。（对于有线连接，选择**以太网**然后点击**网络图标**。）您的本地IP地址将显示在下一个窗口中。

    ![Alt](/public/sav/ip_nat_check_ch/ip_nat_check_23_ch.png =750x)

4. 在**IPv4地址**下查看您的本地IP地址。

    ![Alt](/public/sav/ip_nat_check_ch/ip_nat_check_24_ch.png =750x)

## MacOS
1. 打开**苹果菜单**并点击**系统设置**。

    ![Alt](/public/sav/ip_nat_check_ch/ip_nat_check_31_ch.png =350x)

2. 在左侧面板中点击**网络**，然后选择**Wi-Fi**或**以太网**（对于有线连接），在点击您所链接网络旁边的**详细信息**。

    ![Alt](/public/sav/ip_nat_check_ch/ip_nat_check_32_ch.png =750x)

3. 点击**TCP/IP**，在右边即可查看您的**IP地址**。

    ![Alt](/public/sav/ip_nat_check_ch/ip_nat_check_33_ch.png =750x)

### 请输入您的本地IPv4地址
