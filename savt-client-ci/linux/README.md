# savt-client-cli

## install
1. chmod +x install.sh
2. sudo ./install.sh install

## uninstall
1. sudo ./install.sh uninstall

## usage

### run a probe
1. ./savt-client-cli prober

### set configure
1. ./savt-client-cli config

2. Example: ./savt-client-cli config --enable=false --retrylimit=5

3. For detail, use: ./savt-client-cli config --help

### check version
1. ./savt-client-cli --version
